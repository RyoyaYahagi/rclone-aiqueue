# rclone-aiqueue

個人用の rclone 接続（自分の Google Drive）の説明ページ。Google Cloud の OAuth 同意画面に載せる
ホームページとプライバシー ポリシーを GitHub Pages で配るためだけのリポジトリ。

- ホームページ: https://ryoyayahagi.github.io/rclone-aiqueue/
- プライバシー ポリシー: https://ryoyayahagi.github.io/rclone-aiqueue/privacy.html

方針: 個人を特定できる情報（メールアドレス・フォルダの ID・ホスト名など）を載せない。内容は最小限にする。
